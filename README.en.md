# oclive-school · alternate OCLive source branch

This repository preserves another OCLive source branch. Its package is named `oclivenewnew` at version `0.4.0`; no separate release assets are uploaded here. Its source and documentation are not the current primary release snapshot.

[简体中文](README.md)

## Current project entry points

- [A.I.Live main repository](https://github.com/linkaiheng2233-cyber/oclivenewnew): project introduction and primary development.
- [Main repository releases](https://github.com/linkaiheng2233-cyber/oclivenewnew/releases): read each release's actual notes and assets.
- [Independent OCLive Kernel](https://github.com/linkaiheng2233-cyber/oclive-kernel): Rust Base contracts and example Hosts.
- [Role-pack editor](https://github.com/linkaiheng2233-cyber/oclive-pack-editor): character creation and export.

Recent frontend work or fixes in the main repository are not automatically present in this branch. Likewise, an older path, screenshot or instruction here does not describe the main repository's current state.
